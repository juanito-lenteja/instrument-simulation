# Frontend Documentation

## How to Run

### Install the Requirements
 
1. Install a supported Node.js version (`^20.19.0`, `^22.12.0`, or `^24.0.0`) [here](https://nodejs.org/en/download).
2. Install the Node package manager (npm) [here](https://docs.npmjs.com/cli/v12/commands/npm-install).
3. Install the Angular CLI with `npm install -g @angular/cli@21`.
4. Change directory to Frontend and install the dependencies with `npm ci`.

### Building and Serving the Application

Simply run `ng serve` from the frontend root directory.
